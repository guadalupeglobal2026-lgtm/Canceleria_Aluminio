Fórmulas de corte por tipo

Cada pieza es medida base menos un descuento. Cabezal y riel van a medida total; las jambas laterales entran entre ellos. Para calibrar, pon las medidas de una ventana ya armada en «Ventana de prueba» y compara la columna Prueba con las piezas reales.

Respaldo e importación

Generar respaldo crea una copia en texto de todo el sistema (obras, material y fórmulas) para guardarla aparte, por ejemplo en un documento o en WhatsApp. Importar sirve para recuperar esa copia o para pasar datos de la calculadora anterior en Claude: pega el texto aquí y presiona Importar. Las obras importadas se agregan a las que ya existen.
